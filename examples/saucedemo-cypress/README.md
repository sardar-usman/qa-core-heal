# SauceDemo Cypress

A Cypress login spec with a mistyped test id, aimed at the public SauceDemo site.

Set `SAUCE_USER` and `SAUCE_PASS` in the environment before a live run. The spec reads them through Cypress expose. They are not stored in this folder.

Install Cypress in this folder, then run the heal command from the package script. Heal uses a temporary copy and does not add files here.
